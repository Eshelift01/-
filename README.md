# נחשון • תרגול למבחן המסכם

אתר משחקי תרגול על בסיס „סיכום מבחן מסכם – מגמת נחשון בה״ד 1” (20 נושאים).
ללא לבבות – תרגול חופשי ואינסופי.

## משחקים
- 🎯 שאלון אמריקאי
- ✍️ השלמת היגד (בחירה / הקלדה חופשית)
- 🃏 היגד ותשובה (כרטיסיות)
- ⚖️ נכון / לא נכון
- 🔗 משחק התאמה
- 🔢 סדר נכון
- 🧺 מי שייך?
- 🧠 שליפה מהזיכרון
- ⚡ בליץ 60 שניות
- 🔁 חזרה על טעויות
- 📖 חומר לימוד, 📊 התקדמות לפי נושא

## הפעלה
פותחים את `index.html` בדפדפן – אין צורך בהתקנה.
התוכן נמצא ב-`js/data.js`; השאלות נוצרות ממנו אוטומטית ב-`js/app.js`.
