# סיור בהר הרצל

אפליקציית ווב (PWA) לסיור בהר הרצל, עם שני מסכים:

- **מפה** – המפה האינטראקטיבית של ששת האתרים. אפשר להזיז, להגדיל ולבחור אתר.
- **פלייליסט** – כפתור לכל שירות סטרימינג (Apple Music, Spotify, YouTube Music, YouTube, Deezer, Tidal, Amazon Music). Apple Music פותח את הפלייליסט ישירות; בשאר השירותים הכפתור פותח את TuneMyMusic להעברת הפלייליסט. בתחתית המסך הפלייליסט מוטמע להאזנה בדף.

## הפעלה

אין שלב בנייה. מגישים את התיקייה כאתר סטטי (למשל GitHub Pages: Settings → Pages → Deploy from branch).
בטלפון: "הוספה למסך הבית", והאפליקציה נפתחת במסך מלא ועובדת גם עם קליטה חלשה.

## קישורים ישירים לשירותים נוספים

אם תיצרו את הפלייליסט גם ב־Spotify (או בשירות אחר), הדביקו את הקישור בשדה `link` של אותו שירות במערך `SERVICES` בקובץ `index.html`, והכפתור יפתח אותו ישירות:

```js
{name:"Spotify", link:"https://open.spotify.com/playlist/..."},
```
