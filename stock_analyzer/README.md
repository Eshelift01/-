# 📈 מנתח מניות – הייטק, תעשיות ביטחוניות, אנרגיה ומשאבים

אפליקציה שמנתחת מניות ונותנת המלצת קנייה/החזקה/מכירה, עם גרפים, ניתוח דוחות כספיים,
חוות הדעת של מיכה סטוקס ודוח שבועי בהתראה.

> ⚠️ כלי מחקר בלבד, לא ייעוץ השקעות. ההמלצה היא שקלול אוטומטי של נתונים, ולפני כל החלטה כדאי לבדוק בעצמך.

## מקורות מידע
| מידע | מקור |
|---|---|
| מחירים, נפח, דוחות כספיים, המלצות ומחירי יעד של אנליסטים, תאריכי דוחות | **Yahoo Finance** (דרך הספרייה `yfinance`) |
| גרף אינטראקטיבי | **TradingView** (הווידג'ט הרשמי) |
| חוות הדעת של מיכה סטוקס | הערוץ הרשמי ביוטיוב `@michastocks` (פיד RSS, כתוביות, ואופציונלית YouTube Data API) |

## מה יש באפליקציה
- **גרפים**: נרות יפניים + **ממוצע מחיר 90 יום**, נפח מסחר, ו**אינדיקטור ניצחון הקונים על המוכרים – ממוצע 150 יום**:
  אחוז הימים ב-150 הימים האחרונים שבהם מחיר הסגירה היה גבוה ממחיר הפתיחה (נר ירוק).
  מעל 50% = הקונים שולטים. קו מקווקו נוסף מראה את אותו מדד משוקלל לפי נפח המסחר.
- **ניתוח והמלצה**: ציון 0-100 שמשקלל ניתוח טכני (40%), דוחות כספיים (40%) וקונצנזוס אנליסטים (20%) →
  קנייה חזקה / קנייה / החזק / מכירה / מכירה חזקה.
- **דוחות כספיים**: צמיחת הכנסות ורווח, שולי רווח, חוב והון, נזילות, תזרים חופשי, מכפילים,
  עמידה בתחזיות ברבעונים האחרונים ותאריך הדוח הבא, עם טבלה רבעונית ושנתית.
- **מיכה סטוקס**: סרטונים מהערוץ שבהם החברה מוזכרת, ציטוטים מהכתוביות והערכת טון.
  אפשר להוסיף חוות דעת ידנית (אחרי שצפית) בקובץ `data/michastocks_opinions.json`, למשל:
  ```json
  "NVDA": {"date": "2026-11-10", "opinion": "ממשיך להחזיק, רואה בירידות הזדמנות", "video": "https://youtu.be/..."}
  ```
- **סורק סקטורים**: טבלה מדורגת של כל המניות ברשימה.

את רשימת המניות בכל סקטור אפשר לערוך ב-`analyzer/config.py`.

## התקנה והרצה (במחשב שלך)
```bash
cd stock_analyzer
pip install -r requirements.txt
streamlit run app.py
```
הדפדפן ייפתח בכתובת http://localhost:8501

## התראה שבועית
ה-workflow `.github/workflows/weekly-stock-report.yml` רץ ב-GitHub Actions **כל יום ראשון בבוקר**,
סורק את כל הסקטורים ופותח **Issue** בריפו עם החברות המעניינות של השבוע: ציון גבוה, חציית ממוצע 90,
מעבר של מדד ניצחון הקונים את 50%, תנועות חדות, וגם מניות חלשות. GitHub שולח התראה על ה-Issue במייל ובאפליקציה.
אפשר להריץ אותו ידנית מלשונית **Actions → דוח מניות שבועי → Run workflow**.

ערוצי התראה נוספים (אופציונליים) מוגדרים ב-**Settings → Secrets and variables → Actions**:
| Secret | שימוש |
|---|---|
| `SMTP_USER`, `SMTP_PASSWORD`, `ALERT_EMAIL_TO` | מייל ישיר (ב-Gmail צריך [App Password](https://myaccount.google.com/apppasswords)) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | הודעה בטלגרם |
| `YOUTUBE_API_KEY` | חיפוש בכל היסטוריית הערוץ של מיכה סטוקס, לא רק ב-15 הסרטונים האחרונים |

הרצה מקומית של הדוח: `python weekly_report.py` (הפלט נשמר ב-`reports/`).
