# סיור בהר הרצל

אפליקציית ווב (PWA) לסיור בהר הרצל, עם שני מסכים:

- **מפה** – המפה האינטראקטיבית של שבעת האתרים. אפשר להזיז, להגדיל ולבחור אתר.
- **פלייליסט** – נגן מובנה שמנגן את 25 שירי הסיור ברצף בתוך האפליקציה (דרך YouTube, בלי מנוי ובלי התחברות), עם קודם/הבא ובחירת שיר מהרשימה. ליד כל שיר יש גם קישור ↗ לפתיחה בשירות הסטרימינג של המשתמש (Spotify, Apple Music, YouTube Music, YouTube, Deezer, Tidal, Amazon Music).

## הפעלה

אין שלב בנייה. מגישים את התיקייה כאתר סטטי (למשל GitHub Pages: Settings → Pages → Deploy from branch).
בטלפון: "הוספה למסך הבית", והאפליקציה נפתחת במסך מלא ועובדת גם עם קליטה חלשה.

## עריכה

השירים נמצאים במערך `SONGS` בקובץ `index.html`: שם, אמן, מחרוזת חיפוש (אופציונלית) ומזהה הסרטון ב־YouTube (החלק שאחרי `v=` בקישור). שיר בלי מזהה מדולג בנגן ונפתח בחיפוש YouTube.

- **שיר מדויק:** כדי שכפתור יפתח שיר מסוים ולא חיפוש, מוסיפים לשיר קישור ישיר תחת `links`, למשל `links:{spotify:"https://open.spotify.com/track/..."}`.
- **פלייליסט בשירות נוסף:** אם תיצרו את הפלייליסט גם ב־Spotify (או בשירות אחר), הדביקו את הקישור בשדה `playlist` של אותו שירות במערך `SERVICES`, והכפתור "פתיחת כל הפלייליסט" יופיע גם שם.
