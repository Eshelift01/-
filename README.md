# סיור בהר הרצל

אפליקציית ווב (PWA) לסיור בהר הרצל, עם שני מסכים:

- **מפה** – המפה האינטראקטיבית של ששת האתרים. אפשר להזיז, להגדיל ולבחור אתר.
- **שירים** – שירי הסיור. כל משתמש בוחר פעם אחת את שירות הסטרימינג שלו (Spotify, Apple Music, YouTube Music, YouTube, Deezer, Tidal, Amazon Music), וכל כפתור "האזנה" נפתח באותו שירות. בתחתית המסך מוטמע הפלייליסט המקורי מ־Apple Music.

## הפעלה

אין שלב בנייה. מגישים את התיקייה כאתר סטטי (למשל GitHub Pages: Settings → Pages → Deploy from branch).
בטלפון: "הוספה למסך הבית", והאפליקציה נפתחת במסך מלא ועובדת גם עם קליטה חלשה.

## עריכת השירים

הרשימה נמצאת במערך `SONGS` בקובץ `index.html`. כדי שכפתור יפתח שיר מסוים ולא חיפוש, מוסיפים קישור ישיר:

```js
{n:1, title:"ג'רוז", artist:"ענר שפירא ז״ל", q:"ג'רוז ענר שפירא",
 links:{spotify:"https://open.spotify.com/track/...", youtube:"https://youtu.be/..."}},
```
